# myledgr: Personal Financial Tracker

## 🚀 Overview

**myledgr** is a personal, mobile-first application designed for simple, effective financial tracking and secure authentication. This project aims to provide an easy-to-use tool for managing personal finances, built initially for self-use.

## ✨ Features (MVP Goal)

- **Financial Tracking:** Record and categorize daily expenses and income.

- **Secure Authentication:** User sign-up, sign-in, and session management.

- **Intuitive Mobile UI:** A clean, responsive design optimized for mobile devices.
